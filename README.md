# Homestead Heroes

Official web app for the Homestead Heroes animated universe.

## Experiences
- Cinematic series showcase
- Interactive Homestead Builder mini-game with local progress
- Production Storyboard Hub with editable scene workflow
- Character Bible / continuity reference

## Run
```bash
npm install
npm run dev
```

## Canon
Approved character DNA is the source of truth. Visual concept art establishes the world/style but does not override locked character continuity.
